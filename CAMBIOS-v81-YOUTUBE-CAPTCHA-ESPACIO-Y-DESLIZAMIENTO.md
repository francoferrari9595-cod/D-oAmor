# v81 — Ajuste de YouTube / captcha visible y desplazable

- Se reduce el área del reproductor principal de 380 dp a 260 dp para dejar más espacio a los controles y al botón de verificar.
- Se habilitan zoom por pellizco, vista adaptada al ancho y desplazamiento dentro del WebView.
- Se evita que el scroll vertical de la pantalla Compose intercepte los gestos mientras el usuario desliza dentro de YouTube.
- No se intenta omitir ni resolver automáticamente el captcha; se facilita que el usuario pueda verlo y completarlo manualmente.
- Cambios aplicados sobre el ZIP base recibido en este turno, sin recuperar archivos de versiones anteriores.
