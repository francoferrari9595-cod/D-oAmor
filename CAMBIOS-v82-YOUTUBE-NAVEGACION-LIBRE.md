SINIJ&JOSS v82 — Navegación libre de YouTube

Base: ZIP recibido SINI-JOSS-v81-YOUTUBE-CAPTCHA-SCROLL.zip. No se recuperaron archivos de versiones anteriores.

Cambios:
- Se eliminó la inyección CSS que ocultaba la barra superior, la barra de pestañas y el bloque de recomendaciones de YouTube.
- Se agregó una barra de búsqueda en la pantalla del cine.
- Se agregó acceso al inicio de YouTube para navegar recomendaciones.
- El WebView se amplía durante la navegación para que haya espacio para deslizar y consultar más contenido.
- Los enlaces de YouTube continúan dentro del WebView.
- Mientras el usuario explora YouTube, la sincronización del reproductor compartido no fuerza recargas ni interfiere con la navegación.
- Se puede volver al video compartido mediante el botón correspondiente.

Validación: ZIP creado desde la base recibida. No se pudo compilar en este entorno porque no se encontró el ejecutable Gradle ni el wrapper gradlew. La navegación requiere conexión a Internet y está sujeta a las políticas y verificaciones de YouTube.
